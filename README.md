# 🔥 Caring for Country: Cultural Fire Management Simulation

An educational Pygame simulation illustrating traditional Indigenous cultural fire management (mosaic burning) principles to maintain healthy country, clear fuel loads, and protect biodiversity.

## 🌿 Features
- **Ecological State Transitions:** Land patches dynamically transition across Healthy, Overgrown, and Regenerating states.
- **Interactive Management:** Click overgrown patches to apply controlled cool burns before fuel loads trigger wildfire outbreaks.
- **Biodiversity & Score Tracking:** Real-time metrics for Country Health, player score, and remaining management turns.

## 🛠️ Tech Stack & Requirements
- **Language:** Python 3.x
- **Framework:** Pygame / Pygame-ce
